# Presupuesto Mensual

Una aplicación web simple para gestionar tu presupuesto mensual.

## Características

- Configuración inicial de mes y presupuesto
- Cálculo de ingresos y gastos
- Persistencia local de datos
- Interfaz responsive con Tailwind CSS

## Cómo usar

1. Selecciona el mes y establece tu presupuesto inicial
2. Ingresa tus ingresos y gastos mensuales
3. La aplicación calculará automáticamente tu balance

## Tecnologías utilizadas

- HTML5
- JavaScript (Vanilla)
- Tailwind CSS
- LocalStorage para persistencia de datos
